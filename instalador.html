Antes de empezar necesitás

  • Una cuenta en supabase.com con un proyecto creado
  • Las credenciales del proyecto (las buscamos en el siguiente paso)
  • Acceso FTP o File Manager al hosting con la Extranet instalada

Credenciales de Supabase

Ingresá las credenciales de tu proyecto. Las encontrás en el dashboard de Supabase.

Dónde encontrar las credenciales

  1. Abrí supabase.com e ingresá a tu proyecto
  2. En el menú lateral hacé clic en Settings → API
  3. Copiá la Project URL y la clave anon public

Formato: https://xxxx.supabase.co

Clave pública del proyecto. No uses la service_role key.

Verificar conexión

Comprobamos que las credenciales son válidas y que el proyecto de Supabase está accesible.

Proyecto: —

✓ Conexión exitosa — credenciales válidas

Si falla, volvé al paso anterior y revisá las credenciales ingresadas.
